# 3dprojects

Parametric Fusion 360 scripts for 3D-printable projects.

## Projects

- `raspberry-pi4-gps-case`: Raspberry Pi 4 case with a clip-in NEO-M8N GPS carrier.
- `bracelet-display-stand`: two-piece T stand for displaying bracelets.

## Usage

Copy a project directory into the Fusion 360 Scripts folder, open or create a
Design, then run the script from **Utilities → Add-Ins → Scripts and Add-Ins**.

Dimensions are declared in millimetres at the beginning of each Python file.
